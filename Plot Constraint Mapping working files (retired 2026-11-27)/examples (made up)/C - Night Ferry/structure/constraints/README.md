# Night Ferry: plot constraints (MADE-UP EXAMPLE)

**Not the beats themselves.** What each beat must and must not be. No file here says what happens.

**The work (invented):** an audio drama of 12 episodes, about 30 minutes each, adapted from an invented 1930s radio play, *The Last Crossing*. A night ferry makes one crossing each night; its new radio operator, Marek Holm, comes to suspect that one passenger never disembarks.

## Layers (Step 0)
- **Story units:** the series, and each episode. The episodes are **both**: each has its own small arc (one crossing, one passenger's story), and each carries part of the series' beats.
- **Delivery division:** the end of each episode. It carries no beat, but **it ends on an unanswered question** [Adopted].

## The medium and the original (Inputs 7 and 8)
- **Heard, never seen** [Medium]: everything the listener needs arrives by voice, sound or silence.
- **What the original establishes** [Source]: the captain never leaves the bridge; the ferry makes exactly one crossing a night; the passenger list is read aloud at the start of each crossing. The imaginary author wants to stay close to the original.
