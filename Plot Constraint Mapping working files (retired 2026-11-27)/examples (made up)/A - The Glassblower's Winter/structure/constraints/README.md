# The Glassblower's Winter: plot constraints (MADE-UP EXAMPLE)

**Not the beats themselves.** The conditions each beat must meet and the ones it must not, so that whatever event eventually fills a slot fits the structure, the character and the work's rulings. No file here says what happens.

**The work (invented):** a stand-alone novel of about 300 pages. Ilse Varga, a glassblower in a mountain town, tries to keep her late father's workshop open through one hard winter after its only patron withdraws.

## Layers (Step 0)
- **The novel** is the only story unit.
- **No delivery divisions:** one volume, no parts.
- **Ilse's archetype arc:** one (a novel of about 300 pages supports one), so her arc's Beginning state is on page one.
